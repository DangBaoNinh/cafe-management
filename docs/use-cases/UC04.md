# UC04 — Quản lý tài khoản và vai trò

**Phạm vi** — MVP · **Ưu tiên** — P0

## Mục đích

Cấp quyền customer, staff và admin, đồng thời khóa hoặc mở tài khoản

## Tác nhân

Quản trị viên

## Tiền điều kiện

Admin đang hoạt động; TECH02 đã thiết lập policy và cơ chế khởi tạo admin an toàn.

## Hậu điều kiện

Vai trò hoặc trạng thái được áp dụng từ lần thao tác bảo vệ tiếp theo.

## Luồng xử lý chính

Admin tìm user, chọn vai trò hoặc trạng thái, backend khóa bản ghi thích hợp và lưu thay đổi hợp lệ.

## Luồng thay thế

Mở khóa user hoặc lọc theo vai trò/trạng thái trước khi thao tác.

## Luồng ngoại lệ

Từ chối staff tự cấp quyền, khóa hoặc hạ vai trò chính mình và trường hợp làm mất admin hoạt động cuối.

## Quy tắc nghiệp vụ

[BR02, BR16, BR19](../BUSINESS_RULES.md)

## Dữ liệu đầu vào

User ID, vai trò enum, trạng thái và xác nhận thao tác nhạy cảm.

## Dữ liệu đầu ra

Danh sách cập nhật hoặc lỗi phân quyền/xung đột.

## Phân quyền

Chỉ admin đang hoạt động. User bị khóa không qua middleware dù phiên đã tồn tại.

## Database liên quan

`users`, `sessions`

## UC phụ thuộc

[TECH02](../USE_CASE_TASKS.md#nhiệm-vụ-kỹ-thuật), [UC01](UC01.md)

## Tiêu chí nghiệm thu

Staff/guest nhận 403 hoặc chuyển đăng nhập; giữ ít nhất một admin hoạt động; user bị khóa bị từ chối ở lần truy cập kế.

## Kiểm thử dự kiến

Thử gán giá trị ngoài enum, khôi phục user, khóa khi user còn session, hai admin cập nhật đồng thời.
